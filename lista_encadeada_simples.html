Lista Encadeada Simples

Trabalho de Algotirmos e Estruturas de Dados

Como Funciona uma Lista Encadeada Simples?

Uma Lista Encadeada Simples é uma estrutura de dados dinâmica e linear em que os elementos não ficam armazenados em posições contíguas (vizinhas) na memória. Em vez disso, cada elemento funciona como um "elo" de uma corrente, espalhado na memória e conectado ao próximo por meio de ponteiros.

A Estrutura Base

Diferente dos arrays (vetores), onde o acesso a qualquer elemento é instantâneo porque eles estão enfileirados na memória física, a lista encadeada exige que você percorra a estrutura a partir do primeiro elemento até encontrar o que deseja.

Ela é composta por duas partes principais:

  1. Nó: É a unidade básica da lista. Cada nó é dividido internamente em duas partes:
    • Dado/Carga: O valor real que você quer armazenar (um número, texto, objeto, etc.).
    • Ponteiro/Referência: O endereço de memória que aponta diretamente para onde está o próximo nó da sequência.
  2. Início: Um ponteiro especial que guarda o endereço do primeiríssimo nó da lista. Se a cabeça apontar para o vazio (None), significa que a lista está completamente vazia.

Funções de Ordenação

1. inserir_inicio(lista, dado)

Objetivo

Inserir um novo elemento no topo (começo) da lista encadeada, tornando-o o novo primeiro elemento.

Parâmetros

  • lista: A instância da lista encadeada que sofrerá a alteração.
  • dado: O valor/informação que será armazenado no novo nó.

Funcionamento

A função cria um novo nó contendo o dado informado. Em seguida, aponta o próximo deste novo nó para o nó que atualmente ocupa o início da lista. Por fim, atualiza o início da lista para que passe a apontar para este novo nó.

Implementação (Python)

def inserir_inicio(lista, dado):
    novo_no = criar_no(dado)
    novo_no.prox = lista.inicio
    lista.inicio = novo_no

Detalhamento Linha a Linha

  • novo_no = criar_no(dado): Aloca memória e inicializa um novo nó com o valor passado no parâmetro dado.
  • novo_no.prox = lista.inicio: Faz o ponteiro prox do novo nó apontar para o nó que estava no início da lista (mesmo que a lista estivesse vazia, ou seja, None).
  • lista.inicio = novo_no: Atualiza a cabeça (inicio) da lista para que ela agora reconheça o novo_no como o primeiro elemento.

Exemplo de Uso

# Lista inicial: [A] -> [B] -> None
inserir_inicio(minha_lista, "C")
# Lista resultante: [C] -> [A] -> [B] -> None

Complexidade

  • Temporal: O(1) (Tempo Constante) — Não importa o tamanho da lista, a inserção no início requer sempre o mesmo número de passos fixos.
  • Espacial: O(1) — Alocação de apenas um nó na memória.

2. inserir_fim(lista, dado)

Objetivo

Inserir um novo elemento no final da lista encadeada.

Parâmetros

  • lista: A instância da lista.
  • dado: O valor a ser armazenado no final da lista.

Funcionamento

A função cria um novo nó. Se a lista estiver vazia, esse nó torna-se o início. Caso contrário, um ponteiro auxiliar (cursor) percorre a lista do início até encontrar o último nó (aquele cujo prox é None). Ao encontrá-lo, liga este último nó ao novo nó.

Implementação (Python)

def inserir_fim(lista, dado):
    novo_no = criar_no(dado)

    if lista.inicio is None:
        lista.inicio = novo_no
        return

    cursor = lista.inicio

    while cursor.prox is not None:
        cursor = cursor.prox

    cursor.prox = novo_no

Detalhamento Linha a Linha

  • novo_no = criar_no(dado): Cria o novo nó com o valor informado.
  • if lista.inicio is None:: Verifica se a lista está vazia.
  • lista.inicio = novo_no / return: Se estiver vazia, o novo nó torna-se o primeiro e a função é encerrada.
  • cursor = lista.inicio: Cria uma variável ponteiro apontando para o primeiro elemento para iniciar a varredura.
  • while cursor.prox is not None:: Laço que roda enquanto o próximo nó existir. Ele vai parar exatamente no último nó da lista.
  • cursor = cursor.prox: Avança o cursor para o próximo nó.
  • cursor.prox = novo_no: Conecta o antigo último nó ao novo_no, finalizando a inserção.

Exemplo de Uso

# Lista inicial: [A] -> [B] -> None
inserir_fim(minha_lista, "C")
# Lista resultante: [A] -> [B] -> [C] -> None

Complexidade

  • Temporal: O(n) onde n é o número de elementos na lista. Como a lista não guarda uma referência direta para o fim, é preciso caminhar por todos os nós.
  • Espacial: O(1) — Memória extra usada apenas para o ponteiro auxiliar.

3. remover_inicio(lista)

Objetivo

Remover o primeiro elemento da lista encadeada.

Parâmetros

  • lista: A instância da lista da qual o elemento será removido.

Funcionamento

Verifica se a lista não está vazia. Se houver elementos, o ponteiro de início da lista passa a apontar diretamente para o segundo elemento. O primeiro elemento perde a referência e é coletado pelo Garbage Collector da linguagem.

Implementação (Python)

def remover_inicio(lista):
    if lista.inicio is not None:
        lista.inicio = lista.inicio.prox

Detalhamento Linha a Linha

  • if lista.inicio is not None:: Proteção de segurança para evitar erros caso a lista já esteja vazia.
  • lista.inicio = lista.inicio.prox: A lista "pula" o primeiro elemento, fazendo o inicio apontar para o que vinha logo em seguida.

Exemplo de Uso

# Lista inicial: [A] -> [B] -> [C] -> None
remover_inicio(minha_lista)
# Lista resultante: [B] -> [C] -> None

Complexidade

  • Temporal: O(1) (Tempo Constante) — A remoção exige apenas a reatribuição de um ponteiro.
  • Espacial: O(1) — Nenhuma estrutura de dados adicional é criada.

4. remover_fim(lista)

Objetivo

Remover o último elemento da lista encadeada.

Parâmetros

  • lista: A instância da lista.

Funcionamento

Trata cenários de lista vazia ou com apenas um elemento. Para listas com dois ou mais elementos, percorre a lista com um cursor até encontrar o penúltimo nó. Ao encontrá-lo, quebra o vínculo com o último nó alterando o ponteiro do penúltimo para None.

Implementação (Python)

def remover_fim(lista):
    if lista.inicio is None:
        return

    if lista.inicio.prox is None:
        lista.inicio = None
        return

    cursor = lista.inicio

    while cursor.prox.prox is not None:
        cursor = cursor.prox

    cursor.prox = None

Detalhamento Linha a Linha

  • if lista.inicio is None: return: Se a lista estiver vazia, encerra a função.
  • if lista.inicio.prox is None:: Verifica se a lista possui apenas um elemento.
  • lista.inicio = None; return: Se possuir apenas um, esvazia a lista e encerra.
  • cursor = lista.inicio: Inicializa o ponteiro de busca a partir do começo.
  • while cursor.prox.prox is not None:: Faz o laço parar quando o cursor estiver sobre o penúltimo elemento.
  • cursor = cursor.prox: Avança o cursor.
  • cursor.prox = None: Desconecta o último elemento da lista.

Exemplo de Uso

# Lista inicial: [A] -> [B] -> [C] -> None
remover_fim(minha_lista)
# Lista resultante: [A] -> [B] -> None

Complexidade

  • Temporal: O(n) — É obrigatório varrer a lista até o penúltimo elemento para conseguir remover o último.
  • Espacial: O(1) — Uso de memória auxiliar mínimo e constante.

5. pegar(lista, posicao)

Objetivo

Recuperar o dado contido em um nó localizado em uma posição/índice específico (indexação zero).

Parâmetros

  • lista: A instância da lista.
  • posicao: O índice numérico (inteiro) do elemento que deseja buscar.

Funcionamento

A função percorre a lista a partir do início guardando um contador (indice). Ela caminha nó por nó incrementando o contador. Se o contador igualar a posicao solicitada, o dado do nó atual é retornado. Se a lista terminar antes de encontrar a posição, retorna None.

Implementação (Python)

def pegar(lista, posicao):
    cursor = lista.inicio
    indice = 0

    while cursor is not None:
        if indice == posicao:
            return cursor.dado

        cursor = cursor.prox
        indice += 1

    return None

Detalhamento Linha a Linha

  • cursor = lista.inicio: Inicia a navegação no primeiro nó.
  • indice = 0: Inicializa o contador de posição atual em 0.
  • while cursor is not None:: Garante o percurso seguro até o fim da lista.
  • if indice == posicao: return cursor.dado: Se a contagem bateu com o índice desejado, entrega o valor correspondente.
  • cursor = cursor.prox: Move para o próximo nó.
  • indice += 1: Incrementa o contador da posição atual.
  • return None: Caso a posição não tenha sido encontrada, retorna None.

Exemplo de Uso

# Lista: [A] -> [B] -> [C] -> None (Posições: 0, 1, 2)
resultado = pegar(minha_lista, 1)
print(resultado) # Saída: "B"

Complexidade

  • Temporal: O(n) — No pior caso, terá que andar por toda a lista.
  • Espacial: O(1) — Usa apenas variáveis simples de controle.

6. buscar_dado(lista, dado)

Objetivo

Localizar a posição (índice) da primeira ocorrência de um determinado valor dentro da lista.

Parâmetros

  • lista: A instância da lista encadeada.
  • dado: O valor procurado dentro dos nós.

Funcionamento

Varre a lista a partir do início e compara o valor de cada nó com o valor procurado. Se achar, retorna o índice corrente. Se percorrer toda a lista e não encontrar, retorna -1.

Implementação (Python)

def buscar_dado(lista, dado):
    cursor = lista.inicio
    indice = 0

    while cursor is not None:
        if cursor.dado == dado:
            return indice

        cursor = cursor.prox
        indice += 1

    return -1

Detalhamento Linha a Linha

  • cursor = lista.inicio / indice = 0: Prepara as variáveis de controle.
  • while cursor is not None:: Laço para caminhar pela lista até o fim.
  • if cursor.dado == dado: return indice: Se o conteúdo for o procurado, retorna o índice atual.
  • cursor = cursor.prox / indice += 1: Avança na lista física e na contagem numérica.
