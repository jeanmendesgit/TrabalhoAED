Pilha e Fila

Estruturas de Dados

Como Funciona a Estrutura: Pilha (Stack)

Uma Pilha é uma estrutura de dados linear e dinâmica que segue o princípio LIFO (Last In, First Out — Último a Entrar, Primeiro a Sair). Pense em uma pilha física de pratos: o último prato colocado no topo da pilha obrigatoriamente será o primeiro que você vai retirar.

A Estrutura Base (Pilha)

Todas as operações em uma pilha (inserção, remoção e consulta) acontecem em uma única extremidade, chamada de Topo.

O controle da estrutura é feito de forma simples por meio de uma única referência de entrada chamada topo.

Como Funciona a Estrutura: Fila (Queue)

Uma Fila é uma estrutura de dados linear e dinâmica que segue o princípio FIFO (First In, First Out — Primeiro a Entrar, Primeiro a Sair). Imagine uma fila de banco: a primeira pessoa a chegar é, obrigatoriamente, a primeira a ser atendida.

A Estrutura Base (Fila)

Diferente de uma lista encadeada genérica, a Fila restringe os pontos de acesso:

  1. As inserções acontecem sempre no fim da estrutura.
  2. As remoções acontecem sempre no início da estrutura.

Para tornar essas operações ultraeficientes, a estrutura Fila mantém dois ponteiros: o inicio e o fim.

1. Funções da Pilha (Stack)

1. push(pilha, dado)

Objetivo

Adicionar (empilhar) um novo elemento no topo da pilha.

Parâmetros

  • pilha: A instância da pilha que receberá o elemento.
  • dado: O valor a ser colocado no topo.

Funcionamento

Cria um novo nó para abrigar o dado. Esse novo nó aponta o seu ponteiro prox para o nó que atualmente ocupa o topo. Por fim, a estrutura atualiza a sua referência topo para reconhecer o novo nó instalado.

Implementação (Python)

def push(pilha, dado):
    novo_no = criar_no(dado)

    novo_no.prox = pilha.topo
    pilha.topo = novo_no

Detalhamento Linha a Linha

  • novo_no = criar_no(dado): Fabrica um novo nó na memória contendo o dado informado.
  • novo_no.prox = pilha.topo: O ponteiro do novo nó passa a apontar para o antigo topo (se a pilha estava vazia, aponta para None).
  • pilha.topo = novo_no: O controle da pilha adota o novo_no como o seu novo e atual topo.

Exemplo de Uso

# Pilha inicial: TOPO -> 20 -> 10 -> None
push(pilha, 30)
# Pilha resultante: TOPO -> 30 -> 20 -> 10 -> None

Complexidade

  • Temporal: O(1) — Inserção direta na extremidade de controle, sem nenhuma iteração.
  • Espacial: O(1) — Espaço fixo para um novo nó.

2. pop(pilha)

Objetivo

Remover (desempilhar) e retornar o elemento que está posicionado no topo da pilha.

Parâmetros

  • pilha: A instância da pilha.

Funcionamento

Examina se a pilha possui algum elemento. Se estiver vazia, retorna None. Se contiver dados, captura o valor do nó do topo, atualiza o indicador de topo para o próximo nó (prox) e faz a entrega do valor retirado.

Implementação (Python)

def pop(pilha):
    if pilha.topo is None:
        return None

    valor = pilha.topo.dado
    pilha.topo = pilha.topo.prox

    return valor

Detalhamento Linha a Linha

  • if pilha.topo is None: return None: Validação que previne erros de leitura em pilhas vazias (stack underflow).
  • valor = pilha.topo.dado: Armazena temporariamente a carga do nó do topo.
  • pilha.topo = pilha.topo.prox: Atualiza o topo da pilha para o elemento logo abaixo dele na estrutura.
  • return valor: Retorna o dado que acabou de ser desconectado.

Exemplo de Uso

# Pilha inicial: TOPO -> 30 -> 20 -> None
removido = pop(pilha)
print(removido) # Saída: 30
# Pilha resultante: TOPO -> 20 -> None

Complexidade

  • Temporal: O(1) — Operação imediata de alteração de ponteiros.
  • Espacial: O(1) — Sem consumo extra de memória proporcional à estrutura.

3. peek(pilha)

Objetivo

Visualizar/Espiar o valor que está no topo da pilha, sem desestruturá-la (sem remover o nó).

Parâmetros

  • pilha: A instância da pilha.

Implementação (Python)

def peek(pilha):
    if pilha.topo is None:
        return None

    return pilha.topo.dado

Detalhamento Linha a Linha

  • if pilha.topo is None: return None: Retorna nulo se não houver elementos empilhados.
  • return pilha.topo.dado: Acessa a carga útil do nó atual do topo e a retorna, deixando a pilha exatamente como estava.

Complexidade

  • Temporal: O(1)
  • Espacial: O(1)

4. imprimir_pilha(pilha)

Objetivo

Percorrer toda a extensão da pilha exibindo visualmente os dados de cada nó, partindo do topo até a base da estrutura.

Parâmetros

  • pilha: A instância da pilha que será impressa.

Funcionamento

A função cria uma referência temporária (cursor) apontando para o topo da pilha. Ela imprime o rótulo indicativo do topo e entra em um laço de repetição que continua enquanto o cursor apontar para um nó válido. A cada iteração, exibe o dado do nó atual em uma nova linha e avança o cursor para o próximo elemento abaixo dele na estrutura.

Implementação (Python)

def imprimir_pilha(pilha):
    cursor = pilha.topo

    print("TOPO")

    while cursor is not None:
        print(cursor.dado)
        cursor = cursor.prox

    print("\n")

Detalhamento Linha a Linha

  • cursor = pilha.topo: Inicializa o ponteiro auxiliar na extremidade de controle (o elemento que está no topo).
  • print("TOPO"): Imprime o rótulo textual identificando o início da exibição a partir do topo da pilha.
  • while cursor is not None:: Cria um loop seguro que rodará até que todos os nós empilhados sejam visitados.
  • print(cursor.dado): Exibe o valor do nó atual e quebra a linha automaticamente, simulando o aspecto vertical da pilha.
  • cursor = cursor.prox: Move o cursor para o próximo nó localizado logo abaixo na estrutura.
  • print("\n"): Imprime uma quebra de linha adicional para espaçamento e organização no console.

Complexidade

  • Temporal: O(n) — Onde n é o número de elementos empilhados. É necessário caminhar e visitar cada um dos nós individualmente para imprimi-los.
  • Espacial: O(1) — Consumo de memória fixo e constante, fazendo uso apenas da variável local de ponteiro (cursor).

2. Funções da Fila (Queue)

1. enqueue(fila, dado)

Objetivo

Adicionar (enfileirar) um novo elemento no final da fila.

Parâmetros

  • fila: A instância da fila que receberá o elemento.
  • dado: O valor a ser armazenado.

Funcionamento

A função cria um novo nó. Se a fila estiver vazia, esse novo nó passa a ser, simultaneamente, o inicio e o fim da fila. Caso a fila já possua elementos, o nó que estava no fim aponta seu ponteiro prox para o novo nó, e o ponteiro fim da fila é atualizado para este recém-chegado.

Implementação (Python)

def enqueue(fila, dado):
    novo_no = criar_no(dado)

    if fila.inicio is None:
        fila.inicio = novo_no
        fila.fim = novo_no
        return

    fila.fim.prox = novo_no
    fila.fim = novo_no

Detalhamento Linha a Linha

  • novo_no = criar_no(dado): Aloca memória e inicializa um novo nó com a carga útil (dado).
  • if fila.inicio is None:: Verifica se a fila está completamente vazia.
  • fila.inicio = novo_no / fila.fim = novo_no: Se vazia, o novo nó ocupa o único posto disponível, sendo o começo e o fim.
  • return: Sai da função precocemente pois o trabalho já foi feito.
  • fila.fim.prox = novo_no: Faz o atual último nó apontar para o novo_no.
  • fila.fim = novo_no: Atualiza a referência de controle da fila para que o novo_no seja oficialmente o novo fim.

Exemplo de Uso

# Fila inicial: INÍCIO -> 10 -> 20 (FIM) -> None
enqueue(fila, 30)
# Fila resultante: INÍCIO -> 10 -> 20 -> 30 (FIM) -> None

Complexidade

  • Temporal: O(1) (Tempo Constante) — Graças ao ponteiro fim, não precisamos percorrer a estrutura toda para inserir no final.
  • Espacial: O(1) — Alocação de apenas um nó.

2. dequeue(fila)

Objetivo

Remover (desenfileirar) e retornar o elemento que está na frente (início) da fila.

Parâmetros

  • fila: A instância da fila.

Funcionamento

Verifica se a fila possui elementos. Se estiver vazia, retorna None. Caso contrário, guarda o valor do primeiro nó, avança o ponteiro de inicio para o próximo nó da sequência e, se após essa remoção a fila ficar vazia, limpa também o ponteiro fim. Por fim, retorna o dado removido.

Implementação (Python)

def dequeue(fila):
    if fila.inicio is None:
        return None

    valor = fila.inicio.dado

    fila.inicio = fila.inicio.prox

    if fila.inicio is None:
        fila.fim = None

    return valor

Detalhamento Linha a Linha

  • if fila.inicio is None: return None: Tratamento de erro para evitar operações de leitura em filas vazias.
  • valor = fila.inicio.dado: Salva temporariamente o dado do nó que será removido para poder retorná-lo depois.
  • fila.inicio = fila.inicio.prox: Move a cabeça da fila para o segundo elemento, isolando o primeiro.
  • if fila.inicio is None: fila.fim = None: Se após a remoção a fila ficou vazia, o ponteiro fim também deve ser limpo.
  • return valor: Devolve o valor que estava no início.

Exemplo de Uso

# Fila inicial: INÍCIO -> 10 -> 20 -> None
removido = dequeue(fila)
print(removido) # Saída: 10
# Fila resultante: INÍCIO -> 20 -> None

Complexidade

  • Temporal: O(1) — A operação ocorre direto na cabeça (inicio), sem loops.
  • Espacial: O(1) — Apenas variáveis locais para retenção do dado.

3. front(fila)

Objetivo

Espiar/Exibir qual é o primeiro elemento da fila, sem removê-lo.

Parâmetros

  • fila: A instância da fila.

Implementação (Python)

def front(fila):
    if fila.inicio is None:
        return None

    return fila.inicio.dado

Detalhamento Linha a Linha

  • if fila.inicio is None: return None: Se a fila não contiver nós, retorna None.
  • return fila.inicio.dado: Acessa a carga útil do nó de início e a retorna, mantendo os ponteiros intactos.

Complexidade

  • Temporal: O(1)
  • Espacial: O(1)

4. imprimir_fila(fila)

Objetivo

Percorrer toda a extensão da fila exibindo visualmente os dados de cada nó do início até o final da sequência.

Parâmetros

  • fila: A instância da fila que será impressa.

Funcionamento

A função cria uma referência temporária (cursor) apontando para o início da fila. Ela imprime a tag textual de início e entra em um laço de repetição enquanto o cursor for diferente de vazio. A cada rodada, exibe o dado do nó atual seguido de uma seta indicativa e avança o ponteiro para o próximo elo. Ao final do percurso, encerra a linha indicando o fechamento do encadeamento com None.

Implementação (Python)

def imprimir_fila(fila):
    cursor = fila.inicio
    print("INÍCIO -> ", end="")

    while cursor is not None:
        print(cursor.dado, end=" -> ")
        cursor = cursor.prox

    print("None\n")

Detalhamento Linha a Linha

  • cursor = fila.inicio: Inicializa o ponteiro auxiliar na linha de largada (primeiro elemento).
  • print("INÍCIO -> ", end=""): Imprime o rótulo inicial sem quebrar a linha do console.
  • while cursor is not None:: Cria um loop estrutural seguro que rodará até ultrapassar o último nó existente.
  • print(cursor.dado, end=" -> "): Imprime a informação útil guardada no nó atual junto ao marcador de ponteiro.
  • cursor = cursor.prox: Move o cursor adiante na memória, fazendo-o assumir o próximo nó da fila.
  • print("None\n"): Imprime a indicação de fim de estrutura e quebra a linha do terminal.

Complexidade

  • Temporal: O(n) — Onde n é a quantidade de elementos na fila. É obrigatório passar por todos os nós individualmente para exibi-los na tela.
  • Espacial: O(1) — Consumo de memória fixo, pois utiliza apenas a variável local cursor para realizar o rastreamento.
